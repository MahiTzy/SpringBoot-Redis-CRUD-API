# Spring Boot Redis CRUD API

A Java project demonstrating CRUD operations backed by Redis through a Spring Boot application.

## Overview
Explore the API controllers, data model, Redis configuration, and persistence behavior implemented in the repository.

## Technology
- Java
- Spring Boot
- Redis
- Dependencies declared by the project build file

## Getting Started
1. Install a compatible JDK and Redis server.
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/SpringBoot-Redis-CRUD-API.git
   cd SpringBoot-Redis-CRUD-API
   ```
3. Start Redis and configure the host, port, and any authentication settings expected by the application.
4. Run with the Maven wrapper if included (`./mvnw spring-boot:run`) or the configured build tool.

## API
Inspect controller mappings and request models for the implemented CRUD routes and payload formats. Endpoint details are intentionally not guessed.

## Configuration
Keep Redis credentials and environment-specific settings outside source control.
